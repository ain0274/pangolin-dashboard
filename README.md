### 개발환경

1.  프로젝트 환경설정(vite를 활용한 React 설치): `npm install vite@latest` <br />

2.  CSS 스타일링을 위한 SASS/SCSS 설치: `npm install -D sass` <br />

3.  React Router 설치: `npm install react-router-dom localforage match-sorter sort-by` <br />

4. 차트 구현을 위한 rechart 설치: `npm install recharts` <br />

5. 리액트 아이콘 라이브러리 설치: `npm install react-icons` <br />
